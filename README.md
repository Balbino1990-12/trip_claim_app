# Trip Claim App

A comprehensive Flutter application for managing and claiming trip expenses with technician support and admin dashboards.

## 📋 Project Overview

The Trip Claim App is a complete solution for trip expense management, featuring:
- **User Dashboard**: View and manage trip claims
- **Technician Portal**: Track assigned tasks and claim updates  
- **Admin Dashboard**: Monitor all claims with real-time updates
- **Image Upload**: Attach evidence to claims
- **Notifications**: Real-time updates on claim status
- **WebSocket Integration**: Live admin monitoring
